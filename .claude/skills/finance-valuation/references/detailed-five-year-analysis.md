# 詳細5年分析モード

詳細な財務三表、経営指標、市場指標、経営分析コメントを、同じ原データから作る標準仕様。Speedaのような詳細度という依頼は科目・時系列の充実として受け取り、同サービスへの接続や契約を前提にしない。

## 期間とデータ

- 既定は直近公表済みの連結通期実績5期。対象期・年数・単体指定があれば優先。予想やLTMを実績5期へ混ぜない。
- 科目を縦、年度を古い順に横へ並べる。各社の実際の期末日を表示し、決算期差・短期決算・会計基準差を注記する。
- 平均残高指標のために開始前年末のBSも取得する（5期表示なら6時点）。初年度の前年比には前年の対応PL・CF値も取得する。補助年度は原データに保持し、表示5期と区別する。
- 5期のCAGRは4年間として `(最終期/初期)^(1/4)-1`。初期・最終期が正でない場合はN/M、短期決算等は機械適用せず期間を見直す。「期間成長率」が曖昧なら累計増加率とCAGRを区別して併記する。
- 各社の原科目・原数値と、比較用の統一科目を対応表でつなぐ。公式連結財務諸表の全表示科目と小計を保持し、主要値だけの抽出で詳細三表と呼ばない。注記は下記項目と指標計算に必要な内訳を追加する。
- 原資料の版・対象期・会計基準・通貨・単位・連結範囲・資料ページを保持する。訂正・組替えは最新版と旧値の対応を残す。共通の出典・比較ルールは[financial-analysis.md](financial-analysis.md)に従う。

## 三表の収録範囲

以下は一般事業会社の確認枠。開示科目を基礎とし、科目数を揃えるために未開示値を作らない。銀行・保険等は業種固有の表示科目・指標に置き換え、変更を説明する。

| 表 | 確認する項目・内訳 |
| --- | --- |
| PL | 売上高、売上原価、粗利益、販管費、営業利益、営業外収益・費用、経常利益、特別利益・損失、税引前利益、税金、連結純利益、非支配持分帰属利益、親会社帰属利益、基本・希薄化後EPS。販管費や営業外項目の主要内訳も開示範囲で保持 |
| BS資産 | 現預金、営業債権、棚卸資産、その他流動資産、流動資産合計、有形固定資産、使用権資産、のれん、その他無形資産、投資有価証券、持分法投資、繰延税金資産、その他非流動資産、非流動資産合計、資産合計 |
| BS負債・資本 | 営業債務、短期借入金、1年内返済長期債務、社債、長期借入金、リース負債、引当金、税金負債、その他負債、流動・非流動負債小計、負債合計、資本金、資本剰余金、利益剰余金、自己株式、その他包括利益累計、親会社持分、非支配持分、純資産合計 |
| 営業CF | 間接法の起点利益、減価償却・償却、減損等非資金項目、営業債権・在庫・営業債務増減、その他調整、利息・配当・税金収支、営業CF。直接法は公表区分を保持し、間接法の調整行を捏造しない |
| 投資CF | 有形・無形資産取得・売却、有価証券取得・売却、企業買収・売却、その他投資CF、投資CF合計 |
| 財務CF・現金 | 借入・返済、社債発行・償還、リース返済、株式発行、自己株式取得・処分、配当、その他財務CF、財務CF合計、為替等、現金増減、期首・期末現金同等物 |

内訳と合計は階層で区別し、使用権資産・リース負債等が他の科目に含まれる場合は二重集計しない。IFRS・US GAAPで未開示の経常利益等は非該当とする。BS現預金とCF現金同等物の差は開示注記で照合する。

## 経営指標の標準セット

各指標を5期分表示し、計算不能・非該当でも理由付きのN/A・N/Mを残す。ROICは全体診断で確認し、算出できなければ理由を示す。その他の追加指標は目的と取得情報に応じて採用する。詳細な共通定義は[financial-analysis.md](financial-analysis.md)を参照。

| 分類 | 標準項目 | 定義・解釈 |
| --- | --- | --- |
| 収益性 | 粗利益率、営業利益率、親会社帰属純利益率、ROE、ROA | ROAの既定は親会社帰属純利益／平均総資産と明示。ROEは平均親会社持分。業種に合わせた変更は定義を記録 |
| 成長性 | 売上・営業利益・親会社帰属純利益の前年比とCAGR | 前年がゼロ・負なら差額と黒字化／赤字化を説明し、機械的な伸び率を避ける |
| 安全性 | 自己資本比率、流動比率、有利子負債、ネットデット、ネットデット／EBITDA | 流動比率＝流動資産／流動負債。有利子負債の借入・社債・リース範囲、ネットデットから控除する現金範囲を明示。このモードのEBITDAは営業利益＋対応D&Aを既定とし、共通参照のEBITはこの計算では営業利益と定義。会社調整値と区別 |
| 効率性 | 総資産回転率、DSO、DIO、DPO、CCC | [共通定義](working-capital-analysis.md)。近似・欠損理由と構成3要素を保持 |
| キャッシュ創出力 | 営業CF、設備投資、FCF、営業CFマージン | 設備投資は有形・無形資産の取得支出を正数化。FCF＝営業CF−設備投資、営業CFマージン＝営業CF／売上。投資CF全体を設備投資とみなさない |

効率性の標準項目は総資産回転率、売上債権回転期間（DSO）、棚卸資産回転期間（DIO）、仕入債務回転期間（DPO）、CCC。[運転資本・資金繰りの共通定義](working-capital-analysis.md)に従い5期分の数値または欠損理由を表示する。生産性はデータと事業特性に応じた補足。ROICは全体診断の確認項目とし、算出不能なら理由を残す。追加候補は配当・自己株式取得。金融機関に営業CFやネットデット／EBITDA等を機械適用しない。自己資本が負・極小、期中に符号が変わる場合はROEの解釈不能を説明する。

## 市場指標の標準セット

上場会社では**株価、時価総額、実績PER、PBR**を必須の表示項目にする。未入手は理由付きN/A、EPS・BPSがゼロ以下なら対応倍率を理由付きN/Mとする。非上場は非該当とし、仮の株価を作らない。追加候補は会社予想PER、配当利回り、EV／EBITDA。

- 既定は最新の共通基準日（両市場で確定終値が揃う日）のスナップショット。終値の取引日・市場・通貨・取得日時を記録する。過去5期末の市場指標は要求されたときに追加し、最新株価を過去のEPSへ使い回さない。
- 実績PER＝株価／直近公表通期の基本EPS。採用年度を表示する。希薄化後EPS・LTM・会社予想を用いる場合は別の名称と列にし、実績PERに混ぜない。
- PBR＝株価／基準日時点で入手できる最新公表BPS。期末日を表示し、BPSは普通株主に帰属する持分／対応期末の自己株式控除後普通株式数。優先株等の調整が必要なら根拠を残す。
- 時価総額＝株価×基準日に対応する自己株式控除後普通株式数を分析上の既定とし、株数の時点を記録する。異なる定義の公表値は別掲する。複数株式クラス・ADRでは権利と換算比率を合わせる。
- EPSは期中平均株式数、BPSは期末株式数を使うため、時価総額／利益と株価／EPSが自社株買い等で一致しない場合がある。数値を無理に一致させず定義差を注記する。
- 株式分割・併合は株価、EPS、BPS、株式数を同じ株式単位へ調整する。PER・PBRには配当込み調整株価を使わない。
- 過去市場指標を追加するときは、各期末以前の直近取引日終値と、その時点で公表済みの財務情報を使う。後日公表された同年度決算を対応させる指定なら「期末株価／当該年度実績（事後対応）」と表示し、当時の情報だけによる比較と区別する。

## Excelと後続ダッシュボードへの引継ぎ

形式未指定なら数値と分析コメントを含む新規Excel（.xlsx）を作る。Word（.docx）は明示依頼時だけ作成する。PL・BS・CF・経営指標・セグメントの分析結果と課題を整理し、2社では各区分の比較を加える。後続ダッシュボードには同じ本文・数値・出典を渡す。シート構成は以下を基本とし、ユーザーのテンプレート・構成指定を優先する。2社以上は会社別の詳細表と共通指標の比較を両立させる。[workbook.md](workbook.md)の数式・出典・再計算・表示検証を適用する。

| 順番 | 内容 |
| --- | --- |
| 1 分析要約 | 主要推移・企業比較、5区分の分析と課題（6領域の評価を含む）、市場評価の読み取り、制約 |
| 2〜4 PL・BS・CF | 全開示科目と必要な注記内訳の5期表。原科目との対応、小計の検算 |
| 5 経営指標 | 標準指標の5期表、定義・計算式、適用不能理由 |
| 6 市場指標 | 共通基準日の株価・時価総額・PER・PBR、財務数値の対応期 |
| 7 原データ・出典 | 原数値、補助年度、資料ID・URL・ページ、原科目と統一科目の対応 |
| 8 定義・検算 | 仮定、会計・通貨等の比較条件、貸借・CF・小計の照合、取得できなかった項目 |

経営分析は [analysis-commentary.md](analysis-commentary.md) に従い、各社の6領域、2社比較、改善の優先順位を設ける。「数値の変化・企業差 → 開示資料で確認した要因／分析者の仮説 → 課題・問題点 → 改善案と実行条件・副作用 → 確認KPI」で書き、書籍の考え方と企業の実績出典を分ける。各領域の強み・弱みを数字で支え、株価倍率だけで割安・割高と断定しない。チャートは売上・利益、利益率、資本構成、営業CF・FCFなど説明に必要なものに絞る。

全体診断には [capital-efficiency-analysis.md](capital-efficiency-analysis.md) を適用し、ROEの3要素の5年推移・変化寄与、ROA、定義を明示したROICまたは参考値と未算定理由、資本配分の選択肢をExcelと引継ぎデータへ収録する。明示依頼で作るWordにも含める。

## 完了条件

- 5期×詳細三表の収録と欠損理由、標準経営指標、市場指標、分析コメントが揃っている。データ不足による未完成箇所は明記する。
- 三表の貸借・小計・CF増減、指標の代表値、初年度の平均残高、CAGRの期間、株価とEPS/BPSの単位・時点を確認する。
- Excelを保存し、対象期・単位・主要数値・結論と、後続HTML用の本文・セグメント表・課題の引継ぎを確認する。Wordを明示依頼で作成した場合だけ、その一致と表・改ページ・文字の表示も確認する。
- Excelの数式再計算と表示確認は実施結果を分けて報告する。スキルの参照テストだけで実データ・Excelの検証済みとしない。
- DCF、企業概要ダッシュボード、財務図解、裏決算資料は、それぞれ依頼された場合に追加する。
