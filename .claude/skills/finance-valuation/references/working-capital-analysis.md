# 経営指標5軸と運転資本・資金繰りの判断

通常の企業財務分析・比較で適用する。収益性・安全性・成長性・効率性・キャッシュ創出力（既存表記の資金創出力）を標準の5軸、生産性を補足とする。5軸は分析の切り口であり、既存の本文5区分（PL・BS・CF・経営指標・セグメント）を置き換えない。資本配分は5軸を統合して考える領域として保持する。各軸の全指標を網羅せず、標準項目と事業上重要な項目を扱う。単独指標など明示された依頼範囲を優先する。

## 効率性の標準表示

総資産回転率と以下のDSO・DIO・DPO・CCCを対象期間について標準表示し、欠損・非該当も理由付きで残す。単位は回転率が回、回転期間が日。月数を使う指定では日数と区別する。

| 指標 | 計算式・採用条件 |
| --- | --- |
| 総資産回転率 | 売上高／期首期末平均総資産 |
| 売上債権回転期間（売掛債権回転期間、DSO） | 平均売上債権／対応売上高×対象期の日数。比較用の既定は総売上高分母。掛売上が分離開示され対応が取れる場合は掛売上基準も可。両者を混在させず、総売上基準は現金売上を含むため顧客の実際の回収日数とは異なることを説明 |
| 棚卸資産回転期間（DIO） | 平均棚卸資産／売上原価×対象期の日数 |
| 仕入債務回転期間（買入債務回転期間、DPO） | 平均仕入債務／対応仕入高×対象期の日数。対応する掛仕入高が判明する場合はその範囲を明示。仕入高が未開示なら売上原価で代用し「売上原価基準の近似」と明示 |
| CCC（キャッシュ・コンバージョン・サイクル） | DSO＋DIO−DPO。構成要素と同じ期間・範囲・日数を用い、近似を含む場合はCCCにも近似と表示 |

- 平均は期首・期末の単純平均を既定とする。季節性が強く月次・四半期平均が取得できれば採用理由と計算方法を記す。期首欠損時は平均残高方式を理由付きN/Aとし、期末残高で黙って代用しない。期末残高方式を参考表示する場合は別名・別系列とし、平均方式との比較限界を示す。
- 365固定ではなく対象期の日数（うるう年、52/53週、短期決算を含む）を記録する。比較目的で365日換算するなら全社・全期で規約を合わせ、実日数方式と区別する。
- 売上債権は売掛金・受取手形等、仕入債務は買掛金・支払手形等、棚卸資産は原材料・仕掛品・製品等の採用範囲を保存。営業外債権、設備未払金、借入金を無条件に混ぜない。契約資産、電子記録債権・債務、税の税込／税抜差、債権流動化、サプライヤーファイナンスの影響は重要なら確認する。未開示の合算科目は分離不能を表示し、同一定義の比較を優先する。
- 売上原価には労務費・減価償却等が含まれ得るため、DPO近似の精度は業種で異なる。「売上原価＋在庫増減」だけで製造業の仕入高を捏造しない。サービス業・複合企業では原価と債務の対応を確認する。
- 未入手はN/A、分母ゼロ・負や業種上解釈不能なら理由付きN/M／非該当。確認できた残高ゼロと欠損を区別する。構成要素が欠ければCCCも算出不可とし、欠損を0として合算しない。金融機関など適用不適切な業種は理由と業種固有の流動性指標へ置き換える。
- 2社比較は残高範囲、分母、平均方法、期間を照合。定義差を調整できない場合は数値を保持して比較限界を示し、短いCCCだけで優劣を付けない。

## 数字から支払能力へつなぐ

安全性・効率性・キャッシュ創出力の解説に、次の流れを組み込む。全社に同じ警告文を貼るのではなく、当該企業で確認した根拠、成立条件、判断保留の範囲を記す。

1. **事業モデルと推移**：現金販売／掛売り、前受け、仕入条件、製造・在庫期間、季節性と成長段階からDSO・DIO・DPOの変化を説明する。CCCの増減を3要素に分け、残高変化が営業CFに与えた影響をCF明細で照合する。買収・為替・非資金変動によりBS差額とCFが一致しない理由も確認する。
2. **換金性と期限**：流動比率が高くても、滞留・陳腐化在庫、回収遅延・貸倒懸念債権、拘束現金が多ければ支払余力とは限らない。使用可能現金、期限までの回収・売却見込み、仕入支払・給与・税・借入返済・リース支払を時期で照合する。当座比率への置換だけでも判断は完結しない。
3. **資本と現金を分ける**：債務超過の原因を累積損失、自己株式取得・配当、会計上の調整等に分ける。負の持分だけで即資金ショートとせず、負のCCCだけで安全とも判定しない。営業CFの持続性、投資・返済後の余力、手元資金、利用可能な確約融資枠、借換え条件・財務制限条項を確認する。未確約の調達を確定資金と数えない。
4. **負のCCCの内訳**：顧客からの早い回収と合意された支払条件によるものか、支払遅延や仕入先金融によるものかを区別する。前受金・ギフトカード・契約負債は通常のDSO＋DIO−DPOには直接含まれないため、別途資金効果と履行・返金義務を分析し、二重計上しない。前受けを控除した調整回収日数・調整CCCを補足する場合は標準値と別名・別式で表示し、書籍等の調整後の負の日数を標準DSOやCCCの実測値として転用しない。
5. **定性的な悪化シナリオ**：売上減少、回収遅延、在庫滞留、仕入先の支払期限短縮、借換え難のうち重要な条件を選び、現金への経路と判断が変わる条件を示す。負の運転資本では売上縮小で資金流出となる可能性があるが、必然とせず内訳・タイミングを確認する。数値の仮定を置くストレス試算は依頼とデータがある場合に実施し、会社予想とは区別する。
6. **改善と副作用**：在庫圧縮の欠品、回収短縮の顧客離反、支払延長の仕入先負担・価格条件悪化を含め、施策の条件と確認KPIを示す。DSO短縮・DPO延長自体を経営目的としない。

分析結果には「確認できた事実／解釈・仮説／支払能力を支える条件／悪化時の経路／必要な追加情報・KPI」を短く残す。期限別資金繰り表等が未開示なら確認できない範囲を示し、年間の営業CF黒字から特定日の支払可能性を断定しない。一定の流動比率・自己資本比率・CCCの色分けだけで総合評価を自動決定しない。

## 生産性の補足

事業上意味があり、対応する連結範囲・期間の従業員数がある場合に、従業員1人当たり売上高・営業利益を補足する。期中平均人数／期末人数、正社員・臨時雇用・FTE、外注化の違いを明記する。付加価値額・付加価値率・労働生産性は採用定義と必要内訳が揃う場合だけ追加し、欠損から推計して全社へ強制しない。

## 引継ぎと確認

Excel・共通データ・HTMLで各指標の値、単位、式、原科目・セル／出典、分母、平均方法、日数、欠損理由、近似区分を保持する。既存分析のHTML化では提供データ内で算出できる分を補い、追加計算と明示する。外部追加取得・期間拡張の許可には広げない。不足指標は理由付き表示とし、完成を装わない。

受入確認は、CCC＝DSO＋DIO−DPOの独立計算、3要素の変化の説明、近似・欠損の表示、資金繰りの条件と悪化シナリオ、ExcelとHTMLの一致を含む。
