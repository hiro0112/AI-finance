# 財務図解ダッシュボード

財務の規模・構成・流れを、金額・会計区分・出典を追えるHTMLにする。標準成果物はBox図・サンキー図・STRAC表を収録した単一HTML。3図をページ内のタブ等で切り替える。

## 出力範囲

- 「財務図解」「財務図解ダッシュボード」「3図」「全部」は、3図入りの1HTMLを作る。図の種類を指定された場合は、その図だけを1HTMLにする。
- 図ごとの別ファイルは明示指定された場合だけ作る。別の入口HTMLは追加しない。
- 経営分析ダッシュボードは別のfinancial-analysis-dashboardが担当する。本スキルの実行だけで呼び出したり、経営分析へのリンクを追加したりしない。
- 経営分析ダッシュボードにはBS・PLボックス図が標準で収録される（担当はfinancial-analysis-dashboard）。ボックス図の描画仕様（boxes.md）はその組込みでも共用する。
- 経営分析と図解の両方を依頼された場合は、ボックス図入りの経営分析1HTMLを標準とする。サンキー図・STRAC表が明示された場合だけ、同じ確定データで本スキルがその図の別HTMLを作る。相互リンクは希望された場合だけ付ける。既に依頼された出力を再確認しない。

## 共通データと図別仕様

企業・対象期・連結範囲・出力先を会話から引き継ぐ。既存分析の再利用では元の期間・市場基準日・定義を保持し、追加取得しない。外部取得では指定期間を優先し、未指定は最新公表通期の単年、5年指定は直近公表済み5通期とする。入力経路と対象期を伝え、企業や入力所在が不明な場合だけ確認する。

[共通データ契約](references/multi-year-data.md)で外部取得／既存分析再利用を整理する。単年の会計規約は[data-contract.md](references/data-contract.md)。原科目と集約値、公表値・計算値・描画補正を区別し、欠損と符号を保持する。未開示の経常利益や固定費・変動費を捏造しない。外部取得禁止の指定を守る。

## 制作

[テンプレート一覧](references/templates.md)は描画の参考とし、納品形式は本スキルの単一HTMLを優先する。複数図の新規制作は[分担手順](references/delegation.md)に従う。既存図の統合では、検証済みの描画を再利用して親または統合担当が1HTMLにまとめる。

[共通操作](references/html-interaction.md)に従い、最新年度初期表示、年度と企業の選択、図切替時の状態保持を備える。図・原数値表・期間・出典・注記を同時に更新し、選択期に対応する短い読み取りを添える。

日本語、インラインSVG、外部ライブラリ不要の単一HTML。必要データ・図の実装・出典を内包し、そのHTMLだけを別フォルダへ移しても動くようにする。別HTMLやローカルJSONの読込みを前提にしない。用途を特定の催しに固定しない。ファイル名は `YYYY-MM-DD_企業名_財務図解ダッシュボード.html`。単独図指定では図名を使う。

既存版は保持し、改訂は別版にする。書籍原本は通常制作で開かず、既存分析とスキル内の判断基準を使う。自動コミット・公開はしない。

## 検証と引き渡し

1. `python3 "{SKILL_ABSOLUTE_PATH}/scripts/validate_bundle.py" /absolute/path/financial-data.json` で全年度を検査。出典の正しさと指標値は別途照合する。
2. 各図の全企業・年度・表示モードで会計整合、欠損・赤字・負の自己資本・逆符号CF・NaN/Infinity・負の寸法を点検する。
3. 許可されたブラウザで収録図の切替（複数図の場合）、年度・企業の保持、縮尺、小画面、キーボード操作、印刷を確認。印刷時はそのHTMLに収録した全図と選択条件を表示する。模擬DOM検証と実画面確認を区別する。
4. 納品HTMLが指定数であること、標準なら1ファイル内に3図と必要データがそろい、他ファイルへ依存しないことを確認する。
5. HTMLへのリンク、操作、仮定・未検証事項を報告。SKIPは合格と区別する。経営分析・Excel・Word等は依頼された場合だけ追加する。
