# 経営会議で読む定性分析

全体ダッシュボードの本文・比較・経営課題を作るときに必ず適用する。経営陣・幹部社員が、このHTMLだけで「何が起きているか、なぜ重要か、何が課題か、次に何を判断・確認すべきか」を理解できる水準にする。従来のWordレポートの主要数値、解説、全体診断、比較、課題、優先順位、出典・制約を収録する。Wordを作成・参照することは完成の条件ではない。

## 本文の順序と読みやすさ

- [探索型の構成](dashboard.md#探索型の構成)を標準とし、冒頭に対象企業・期間・比較条件と問いを置く。図表・比較の後に全体診断と課題候補・優先理由を示す。結論先行の明示指定がある場合は全体結論を先に置ける。どちらもPL・BS・CF・事業別の動きを結び付ける。
- 本文はPL、BS、CF、経営指標、セグメントの5区分。各区分の見出しは内容が分かる日本語にし、数表・チャートの近くに分析結果と導かれる課題を置く。
- 終盤に課題と優先順位の候補、対応の方向・実行条件、確認KPI・追加資料をまとめる。探索型では、最後のまとめで各社の「まだ分からないこと」と方向性の選ぶ条件を示し、どの条件で判断が変わるかを問い返す。分析上の提案と会社公表の計画を区別する。
- 結論と主要な分析・課題は通常表示で読めるようにする。定義、全明細、細かな補足、5区分の各社の長い本文は折りたたみにできる（dashboard.mdの既定に従う）が、本文を短いカードやツールチップだけに縮約しない。同じ数値・結論を複数の欄で繰り返さず、詳しい根拠は1か所に置いてリンクでたどれるようにする。用語（手元資金・金融資産など）は全体で同じ意味に統一する。図の色・大小だけで意味を伝えない。
- PLは損益計算書、BSは貸借対照表、CFはキャッシュフロー計算書と初出で説明する。ROIC等も短い意味を添える。専門用語を言い換えつつ、金額・率・ポイント・定義の精度は保つ。
- 印刷時には対象会社・期間・単位を残し、全区分の本文・比較・セグメント表・課題・注記を展開する。出典を読まなくても論旨が分かり、根拠を確認したい読者は該当出典へたどれるようにする。

## 必須の5区分

探索型の各区分は「見るところ → 主要数値と対象期間の変化 → 分析結果・背景 → 経営への影響 → 課題候補と判断条件」で記述する。区分の冒頭は問いの形にせず、「見るところ：」の一行で、何を見るかと強み・弱みとのつながりを案内する（問いは冒頭の3問だけにする）。結論先行が指定された場合は分析結果を先に置ける。背景は開示で確認した事実と分析者の仮説を分ける。数値の増減を言い換えるだけでなく、事業上の意味を説明する。資料不足なら判断保留、必要資料、判断できない範囲を記す。未入手項目の見出しだけを消さない。

| 区分 | 分析結果として説明すること | 課題につなぐ観点 |
| --- | --- | --- |
| PL | 売上・利益の推移、売上原価・販管費、利益率、各利益段階、一時損益。価格・数量・構成・為替等は開示の範囲で説明 | 増収が利益に結び付くか、採算低下の要因、収益の持続性、改善を要する事業や費用 |
| BS | 資産構成、運転資本、現預金・金融資産、借入・返済期限、自己資本の変化。期末残高と平均残高を区別 | 流動性と支払能力、資産効率、資金の拘束、調達と資本配分。現金を全額余剰扱いしない |
| CF | 営業・投資・財務CF、利益と営業CFの差、運転資本、設備投資、FCF、還元・借入と現金増減 | 利益の現金化、成長投資の回収、資金不足の持続性、還元・返済と投資の両立。FCF赤字だけで失敗としない |
| 経営指標 | 成長性・収益性・安全性・効率性・資金創出力の水準と推移、ROIC・ROA・ROE、デュポン分解。市場指標があれば基準日と期待・リスクの関係 | 改善を要する要因と優先順位、事業改善と分母圧縮の区別、指標同士の整合。資本コスト未算定なら価値創造の判定は保留 |
| セグメント | 各社の事業別売上・利益・利益率と推移、主力・成長・不振事業、連結増減への寄与、事業構成 | 各事業の採算と成長、依存・集中、改善や資源配分の論点。利益率のみで事業ROICを評価しない |

各社の成長性・収益性・安全性・効率性・資金創出力・資本配分という6領域の評価を、この5区分と全体診断の中でカバーする。区分を増やすために同じ文章を重複させない。該当資料があって顕著な問題が見当たらない場合は、その結論と維持条件・監視点を示す。

## 2社比較は5区分それぞれで行う

PL・BS・CF・経営指標・セグメントの各区分に「観点／A社の数値と分析／B社の数値と分析／差の背景・比較限界／A社の課題／B社の課題」の表または同等の比較本文を設ける。数表を横並びにするだけ、個社別レポートを続けるだけ、末尾に総合比較を一つ置くだけでは完了しない。比較の中でも各社の特徴・強み・問題点が読めるようにする。

- 同じ指標の水準だけでなく、推移と構造の違いを比較し、共通課題と各社固有の課題を示す。根拠がない総合順位や因果の断定を避ける。
- 期間・規模・会計基準・通貨・事業モデルの差を該当箇所で説明する。原通貨額の単純倍率を避け、適切な換算条件または比率・構成比・各社内の変化を使う。
- セグメントは各社の開示区分を保持し、経済的に対応する事業だけを条件付きで比較する。対応しない場合は事業構成、成長源・収益源、集中度、資源配分の違いを比較する。名称が似るだけで同一事業に統合しない。
- 相手から学べることと転用条件を述べ、事業特性が異なる相手の利益率・資本政策をそのまま目標にしない。
- 単独社では比較欄を省く。単年・2期など指定期間を守り、比較のための架空企業・年度を追加しない。

## セグメント表・解説の保持

- 各社について事業を行、対象期ごとの売上・利益・算出可能な利益率を列にした表をHTML本文に内包する。ExcelやWordへのリンクで代替しない。
- 外部顧客売上／内部取引込み売上、営業利益／調整後利益／EBITDA等の定義を見出し・注記に残す。消去・全社費用・調整と連結合計を開示に応じて載せ、一致・丸め差・未照合の状態を表示する。消去行の利益率は対象外。
- セグメント変更・組替後比較値・比較不能期を説明する。内部取引込み売上を無注記で連結売上に対する構成比としない。報告利益と調整後利益を混同せず、調整根拠を残す。
- 主要事業の役割、売上と利益の伸びの違い、利益率の変化、連結増減を支える／押し下げる事業、そこから導かれる課題を数値で説明する。赤字・極小利益では成長率や利益構成比の意味を確認し、適切なら増減額・N/Mを使う。
- 単一セグメント、利益未開示、資料未入手を区別し、入手できた売上等は掲載する。未開示利益を0や推定値で埋めない。比較不能でも理由と必要資料を示す。

## 経営課題のまとめ

先頭に本質的な課題を置く。定義と必須欄は[本質的な課題の抽出](../../finance-valuation/references/analysis-commentary.md#本質的な課題を抽出する)に従い、5区分の本文へ戻れる参照を付ける。その後の優先順位の各課題には、対応する本質的な課題を明記する。

課題ごとに「会社・対象事業／根拠となる5区分の分析／経営への影響／優先理由／対応の方向と条件・副作用／確認KPI・必要資料」を示す。探索型の優先順位は分析上の案として示し、読み手が変更する際の根拠・判断条件を添える。複数区分から同じ課題が導かれる場合は一つにまとめて参照する。対応策を公表済み施策と分析者の提案に分け、判断に必要な情報が不足する施策は条件付きにする。根拠のない効果額・期限・目標値を置かない。

## 運転資本・資金繰りの本文

[共通判断基準](../../finance-valuation/references/working-capital-analysis.md)に従い、CCCと3要素の推移、事業モデル、資産の換金性、支払期限、営業CF・調達余力を関連付ける。高流動比率でも支払不能となり得る条件、負の持分や負のCCCの背景を当該企業の事実から検討する。負のCCCから安全を自動判定しない。重要な定性的悪化シナリオ、判断の成立条件、不足資料・KPIを本文に残す。

## 受入確認

- 総資産回転率・DSO・DIO・DPO・CCCの標準表示、近似・欠損理由、CCCの独立計算、事実から支払能力への解釈と悪化シナリオを確認する。

- 本文の最後に「強み・弱み・課題・今後の戦略の方向性」のまとめがあり、各項目が根拠の数値と本文へたどれること、課題が本質的な課題と一致すること、戦略の方向性が各社2つの性格の違う選択肢で、条件・リスク・KPI付き、推奨や順位を付けていないことを確認する。

- 指定された構成モードを確認する。未指定なら探索型とし、冒頭で結論・推奨順位を確定していないか、問いを末尾に添えただけになっていないかを確認する。
- 問いごとに「見る指標・図表／比較する年度・企業等／確認できた事実／解釈・仮説とその限界／人間が判断する論点」をたどる。問いと操作・根拠の対応がなく、質問カードを飾っただけの構成は修正する。
- 最後のまとめに、まだ分からないことと方向性の選ぶ条件があり、読み手が根拠を選び、優先課題や判断を変える条件を考えられるか確認する。分析の欠落、事実の曖昧化、根拠のない対立仮説で判断余地を作らない。

- 収録一覧で「各社×5区分」「2社なら比較×5区分」「セグメント表と解説」「全体診断」「課題と優先順位」「出典・比較条件・制約」の元データとHTMLの見出し／アンカーを対応させる。未入手・非該当は理由と必要資料を確認する。
- 既存Word・分析メモがある場合は、その重要論点・主要数表・留保事項を一覧に対応付ける。統合・言い換えは可能だが、要約で分析や課題を落とさない。Wordがない新規分析は本要件を基準にする。
- 各区分の主張を少なくとも一つ根拠までたどり、会社・期間・値・定義・出典との一致を確認する。重要な結論と課題は全件照合し、仮説が事実に変わっていないかを点検する。
- 経営陣が読む立場で「何が起きたか／なぜ重要か／各社の課題は何か／何を判断・確認するか」に本文だけで答えられるか確認する。数表や短い評価語だけの区分は書き直す。
- 年度連動する値と、固定期間の比較・総括を区別する。過去年度へ切り替えた際に最新期の文章を過去期の分析に見せない。
- ROE変化の寄与（pt）の表示単位を本文の値と照合し、100倍などの換算違いがないか確認する。
- 実ブラウザの通常表示・小画面・印刷で全区分、表、折りたたみ、本文へのリンクを確認する。ブラウザ未確認と内容確認済みは別に報告する。数値スクリプトの成功だけで定性分析の完全性・品質を合格としない。
