# 図別制作と単一HTMLへの統合

以下は標準の統合出力の手順。明示された分割出力では図別HTMLを納品し、統合を省く。単独図は親が担当する。

共通データ確定後、新規の3図制作はBox・サンキー・STRACの3担当へ分担する。利用可能枠に応じて順次／並行実行し、担当を利用できなければ親が作る。既存3図をまとめる改訂は親または統合担当が行い、描画の再制作は不要。

## 担当への指示

共通JSON・dataset_id、担当図仕様、共通操作、企業・年度・出力先を渡す。各担当は統合用の描画部品と検証結果を返す。部品は作業用であり、3つの別HTMLを最終納品としない。原値・出典・欠損を保持し、データ再取得や元スキルの再呼出しをしない。

親または統合担当は、確定した1つのHTMLに3図を組み込み、年度・企業の選択状態を共通化する。DOMのID、CSS、JavaScriptが衝突しないようにし、図の切替と印刷を検証する。

## 統合確認

- 全図の同一データ・期間・単位・会計区分を照合。連結純利益と親会社利益、純資産と自己資本を区別する。
- 修正が必要なデータは親が一度だけ直し、全図へ反映する。
- 納品HTMLは標準1ファイル。3図、原数値表、出典を内包し、外部のHTML・JSONがなくても動くことを確認する。
- 年度・企業・図の切替、縮尺、欠損、赤字、不正URLへの復帰、キーボード操作、印刷で収録全図を確認する。実画面未確認は報告する。
- 経営分析ダッシュボードにはBS・PLボックス図を標準で収録し、担当はfinancial-analysis-dashboard。本手順の3図統合HTMLは、サンキー図・STRAC表を含む図解を明示依頼された場合に使う。データは共有可能だが、相互リンクは必須ではない。
