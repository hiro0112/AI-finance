# BS・PLボックス図

## 作るもの

対象企業ごとにBSとPLを横並びにする。2社なら計4箱、1社なら2箱を一枚に載せる。初期表示は共通金額縮尺。外枠の幅を統一し、同額は同じ高さ、下端も共通にする。会社名・事業範囲・会計期間・総資産・売上高を各箱の近くに記載する。構成比表示は補助の切替として用意する。

- BS：左半分に流動資産／固定・非流動資産、右半分に流動負債／固定・非流動負債／純資産。
- PL：売上列、その右に売上原価と粗利益、粗利益の右に販管費・その他営業費用・営業利益を置く入れ子構造。売上原価と変動費、販管費と固定費は同義ではない。
- 規模差が大きい場合も金額表示の小さい会社だけ拡大しない。構成比切替と直下の明細表で可読性を補う。
- 箱が小さく文字を置けない項目は省略線・参照番号・直下表で示す。小さい箱に最低高さを付けると比例関係を壊すため行わない。
- 図の描画に必要なデータ・JavaScript・CSSはHTMLに内包する。外部CDNを必須にしない。

## データ契約

各社ごとに以下を保存する。値は公表原単位のまま保持し、表示換算値・図形用調整値を別に計算する。

| 区分 | 必要な項目 |
|---|---|
| 識別 | 会社名、対象事業・連結範囲、会計基準、期首・期末、通貨、原単位倍率 |
| BS | 総資産、流動資産、固定・非流動資産、流動負債、固定・非流動負債、負債合計、純資産合計 |
| BS補足 | 親会社持分、非支配持分、有形固定資産、投資有価証券など、比較に必要な開示項目 |
| PL | 売上高、売上原価または明示した費用集約、販管費、その他営業費用、営業利益 |
| 根拠 | 公式資料名、公開日、URL、PDFページ、値の種別（公表・独自集計・仮定）、集計式 |
| 表示定義 | `costLabel`、`grossLabel`、資本の表示名、図に含めない項目、比較上の差 |

BS右側には原則として非支配持分を含む純資産を使う。親会社持分のみを置く場合は、非支配持分を別箱で示し、左右を必ず整合させる。純資産比率を無条件に「自己資本比率」と呼ばない。

費用の機能別・性質別表示が異なる会社では、図に必要な項目を独自集約してよい。ただし集約式と名称を表示し、未開示の「売上原価」「粗利益」「人件費」を捏造しない。独自集約した費用控除後利益を、比較先の公表粗利益と同一定義に見せない。

## 縮尺と通貨

金額モードは次の順で座標を求める。

1. `共通通貨額 = 原数値 × 原単位倍率 × 共通通貨への換算率`。
2. 複数年では対象全年度を含め、描画対象の全会社・BS・PLから、必要な最大の正側範囲と負側範囲を求める。
3. ラベル用余白を除いた領域に収まる共通スケールを決める。
4. `高さ = 共通通貨額 × 共通スケール`。符号は高さを負にするのではなく、正側・負側の配置に反映する。

最大値を総資産だけで決めない。売上高が総資産を超える会社、負債が資産を超える会社、営業損失が大きい会社も考慮する。固定の最大金額・固定の会社IDによる通貨換算は、汎用版では使わない。

構成比モードはBS＝総資産100%、PL＝売上100%。異なる会社の金額規模を比較できない旨を明示する。分母が0以下の場合は比率を計算せず、理由付きN/Mを示す。

為替は、実際の期末／期中平均レートによる換算か、比較用の単一仮定レートかを選び、レート・日付・出典または仮定であることを表示する。単一仮定レートならBSとPLに適用した模式的比較であることを説明する。元データ表には元通貨・元単位を必ず残す。入力レートは有限かつ正の範囲に検証し、欠損や空欄を0扱いしない。

## 負の純資産・赤字・端数

### 負の純資産

`資産 = 負債 + 純資産` を維持する。右側の負債を資産の下端より超過させ、その超過区間を斜線などで示し、「負債超過額＝純資産のマイナス」と注記する。この区間は負債の一部であり、追加の正の資本ではない。負債にさらに絶対値の純資産を足して二重描画しない。負債超過額に応じて下側余白とラベル位置を動的に確保する。

### 営業赤字・粗損失

既存の正の利益を前提にした入れ子箱へ負値をそのまま投入しない。費用が売上を超える場合は、ゼロ線を持つ符号付き配置などへ描画方式を変え、超過費用／営業損失を識別する。粗損失なら粗利益を正の親箱として使う入れ子も成立しないため、別レイアウトを実装する。赤字例で検証するまで「赤字対応済み」と報告しない。

### 端数

公表値同士の差をまず計算する。資料の原単位で説明できる丸め差のみ、専用の図示調整値または明示した残差へ配分する。原数値を上書きしない。調整額・調整箇所を注記とツールチップに残す。既存例の「1原単位以内」は当該資料に対する扱いであり、全会社へ機械適用する一般許容値ではない。大きな不一致は資料・単位・項目範囲を再確認し、無理に調整して描画しない。

## 既存テンプレートを再利用する際の境界

- 基本型：同一通貨、正の資産・売上・粗利益・営業利益、正の純資産を持つ2社に対応する。営業利益より下の純利益・税金・配当との厳密なBS連結は実装していない。
- 日米比較型：原単位と通貨の異なる2社、比較用の単一換算レート、負の資本を斜線で示す例がある。会社IDに依存する換算・丸め補正、固定の下側余白、総資産だけを使う最大縮尺は汎用処理へ置き換える必要がある。
- どちらも、任意の大幅債務超過、営業赤字、粗損失、売上ゼロ、多社比較にそのまま対応する汎用エンジンではない。対象データに合わせて座標計算とラベル配置を改修する。

## 検証と完成条件

- 元資料の期間・通貨・単位・連結範囲と数値を照合する。再利用した値と、新たに検証した値を区別する。
- 原数値と調整後数値の双方で、BS左右、資産内訳、負債内訳、PLの売上＝費用＋利益を確認する。
- 金額・比率の両モード、換算入力の有効／無効値を実行し、NaN・無限値・負の矩形寸法・図域からのはみ出しを検出する。
- 金額モードで任意の2箱の高さ比が換算後総額比と一致すること、共通幅・共通基準線を確認する。
- HTMLに埋めたSVGの名称・額・比率と、明細表・元データ表の値を照合する。
- 実際のブラウザで標準幅・狭い幅・印刷表示、切替、入力、文字欠けを確認する。権限制限があれば無理に回避せず、静的・数値検証と未実施の目視検証を分けて報告する。
- 図の近くに「BSは期末ストック、PLは年間フロー」「BS左右およびPL売上列・粗利益列は同額の重複表示なので足さない」を記載する。

## 複数年度の場合

[multi-year-data.md](multi-year-data.md)の年度別データと[html-interaction.md](html-interaction.md)の共通操作を使用する。最新年度初期表示、年度切替、同一縮尺、年度別注記・出典を適用する。統合出力では図切替時に選択状態を保持し、過去年度も検証する。
