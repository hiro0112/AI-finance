# 財務三表サンキー図

BS・PL・CFを独立した3段として、選択企業の1枚にまとめる。三表を一本の現金フローに接続しない。BSは期末残高、PLは期間損益、CFは期間増減と期首・期末資金。図の下に三表間の照合を置く。

## 入力と表示

- 企業名、連結範囲、会計基準、開始・終了日、BS基準日、原通貨、公表金額単位、出典URL・該当ページを保持する。
- BS：総資産、流動資産、現預金、流動有価証券、有形固定資産、流動・固定負債、負債合計、純資産。純資産と親会社株主持分は混同せず、後者を使う場合は非支配株主持分等も別に含めてBSを照合する。
- PL：売上、売上原価相当額、販管費、その他営業費用、営業利益、当期純利益。営業利益と純利益は別フィールドにする。公表粗利益がある場合は公表値も保持する。
- CF：期首・期末資金、営業・投資・財務CF、換算差額、その他の公表された資金増減。**CFは全項目、増加を正、減少を負**で統一する。旧データの「純支出の絶対額」は取り込み時に符号変換する。
- 公表値を計算の原本とし、表示丸め・換算値・図示調整は別に管理する。欠損をゼロ扱いしない。
- 原通貨表示と共通通貨表示は任意。換算レート・日付または仮定を明示する。各段を個別に正規化する場合、帯の太さで企業間・三表間の規模を比較できない旨を明記する。

## 三段の構成

### BS：資産構成 → 合計 → 負債・純資産

通常は左に現預金・流動有価証券、その他流動資産、有形固定資産、その他非流動資産、中央に総資産、右に流動負債、固定負債、純資産を置く。内訳は業種と開示に合わせる。使用権資産を有形固定資産に含めるか別置きするかを確認し、二重計上しない。

純資産 `E < 0` の場合は負の太さを描かず、`総資産 A + 不足分 (-E) = 負債 L` と再構成する。左に「不足分＝純資産のマイナス※」を加え、中央を「総資産＋不足分※」、右を負債とする。**不足分は資産や流入ではなく、負の残高を照合する補助値**と図の直下で説明する。純資産を正の資金源として右側に置かない。

### PL：売上 → 売上原価・粗利益 → 販管費等・営業利益

`G = 売上 - 原価相当額`、`G = 販管費 + その他営業費用 + 営業利益 + 明示した端数差` を満たす。原価区分が異なる企業では「店舗関連費用」「費用控除後（独自集約）」など実態に即して命名し、比較先の公表原価・粗利益と同義だと装わない。

原価に材料費以外の人件費・施設費等が含まれる場合も内訳を注記する。営業損失や負の粗利益を検出したら通常の枝分かれへ負値を渡さず、「売上＋損失額＝営業費用合計」の照合型へ切り替え、損失額が収益ではない旨を明示する。

### CF：期首＋増加 → 配分合計 → 期末＋減少

符号で配置を決め、営業CFは常に左・投資CFは常に右という固定をしない。

```text
F = [営業CF, 投資CF, 財務CF, 換算差額, その他公表増減]
r = 期末資金 - (期首資金 + sum(F))
流入側 = 期首資金 + sum(max(f, 0) for f in F) + max(r, 0)
流出側 = 期末資金 + sum(max(-f, 0) for f in F) + max(-r, 0)
```

`r` は後述の丸め差と確認できた場合のみ「端数補正」として加える。営業CFが負なら右側「営業CF・純支出」、投資CFが正なら左側「投資CF・純流入」。換算差額と財務CFも同様。ゼロ項目は省略できる。中央は「期首資金＋当期流入」の図示用合計で、公表指標や売上ではない。

設備投資・配当・自己株式取得は純CFの内訳。補足表示しても純CFに再加算しない。期首・期末資金が負値・定義不整合の場合は通常形を適用せず、当座借越などの表示範囲を確認する。

## 三表間の補足

- `当期純利益 + 非資金損益・運転資本・税等の純調整 = 営業CF`。純利益の連結範囲をそろえる。調整残差を内訳の根拠なしに減価償却と命名しない。
- `CF期末資金 + 定義・範囲の純差額 = BSの対応する現預金等`。同額を事前に仮定せず、差額を全額定期預金と断定しない。
- 利益は純資産の増加要因だが、配当・自己株式取得・その他包括利益等が影響する。利益全額がそのまま純資産に積み上がる矢印にしない。

## 丸めと帯の検証

公表精度と集計項目数から説明できる丸め差だけを調整する。企業別に「常に1」などの固定補正を埋め込まない。残差が説明できなければ、転記・単位・対象期間・内訳範囲を再確認し、無理に合計を合わせない。

- 原数値表は公表値を保持。図示でその他項目に吸収した差または独立調整帯の金額・符号・適用箇所を注記する。
- 調整が表示上 `0.0億円` になる場合、「1百万円」等の原単位または十分な桁数を併記する。
- 各リンク値は有限かつ非負。各ノードの入リンク合計・出リンク合計を金額単位で検証し、接続が存在する各側がノード額に一致することを確認する。終点の入側、始点の出側も対象。
- BS合計、PLの各分岐、CFの期首から期末への照合を別々に検証する。許容する公表丸め差と、描画計算の浮動小数誤差は区別する。
- 各列の高さは `sum(値×縮尺) + gap×(ノード数−1)` で決める。ノード数が増えるケースに合わせ、上下のラベル余白を含むviewBoxを確保する。細い帯のラベルは引出線や一覧へ移し、帯だけを最小高さで膨らませない。
- 企業・表示単位の全状態で数値、NaN、負寸法、文字の切れ・重なりを確認する。印刷は1社1枚を基本とし、三段・注記がページ内に収まるか確認する。実際に目視しなければ目視済みと報告しない。

最小の境界ケース：BS `A=100, L=130, E=-30` は補助値30を加えて130対130。CF `期首100, 営業−20, 投資+40, 財務−30, 換算−5, 期末85` は流入140対流出140。期末だけを+1／−1した公表丸め差ケースは補正がそれぞれ左／右に置かれることを確認する。

## 複数年度の場合

[multi-year-data.md](multi-year-data.md)の年度別データと[html-interaction.md](html-interaction.md)の共通操作を使用する。最新年度初期表示、年度切替、同一縮尺、年度別注記・出典を適用する。統合出力では図切替時に選択状態を保持し、過去年度も検証する。
