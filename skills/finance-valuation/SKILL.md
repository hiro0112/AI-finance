# 企業財務分析・バリュエーション

公開情報と提供資料から、計算・出典・判断の根拠を追える分析を作る。投資銀行の実務を参考にするが、特定の銀行への所属・監修・品質保証を名乗らない。

## 依頼の範囲と成果物

対象企業、目的、期間、評価基準日、通貨、形式は会話から引き継ぐ。判断を左右する不足だけ確認し、既回答を聞き直さない。指定された年数・項目・ツール・形式を優先する。

| 依頼 | 適用する内容 |
| --- | --- |
| 財務分析・企業比較 | 必要な期間の分析とコメント。形式未指定なら新規Excel（.xlsx）。通常分析を自動的に5年一式へ広げない |
| 詳細5年分析・Speedaのような詳細分析 | [詳細5年分析](references/detailed-five-year-analysis.md)の三表・指標・市場指標・コメント。5年の売上だけ等の指定には広げない |
| 企業価値評価 | [valuation.md](references/valuation.md)から依頼と資料に適した手法を選ぶ。既知の値・仮定・試算を分け、感応度と判断が変わる条件を示す |
| 個別指標・数表のみ | 指定範囲に限定し、全文分析や別成果物を強制しない |

財務分析だけ、またはPER・PBRの掲載だけならDCF・目標株価を追加しない。Wordは明示依頼時だけ作る。新規ブックの依頼では既存ブックを変更しない。

## 原資料と計算

[financial-analysis.md](references/financial-analysis.md)を読み、期間・会計基準・連結範囲・原単位をそろえる。原数値を保存し、公表値・独自計算・換算・調整を区別する。

公式IR、有報、決算短信、規制当局提出書類を優先し、数値は本文・表で確認する。提供資料のみという指定を守る。株価・金利・市場倍率は基準日と取得日時を確認する。有料データ接続は必須にしない。

数値ごとに会社、期間、単位、値の区分、資料名、公開日、URL、PDFページ（異なれば印刷ページも）を残す。提供値はその旨、訂正・組替値は元資料との差と採用理由を記録する。未入手を推測で埋めない。

## 分析と判断

通常の財務分析・企業比較では次の参照を読む。個別指標・数表のみの指定は該当部分に限る。

| 判断領域 | 必須の内容と詳細 |
| --- | --- |
| 経営指標・資金繰り | [working-capital-analysis.md](references/working-capital-analysis.md)：収益性・安全性・成長性・効率性・キャッシュ創出力の5軸、生産性は補足。総資産回転率・DSO・DIO・DPO・CCCを標準に含め、近似・欠損理由を表示。指標だけで判定せず、事業モデル、換金性、支払期限、営業CF、調達条件、悪化シナリオを検討 |
| 各社分析・比較・課題 | [analysis-commentary.md](references/analysis-commentary.md)：PL・BS・CF・経営指標・セグメントの5区分ごとに分析と経営課題。2社なら各区分で差の背景、共通／固有課題、改善の示唆を比較。セグメント表・解説、優先順位を保持 |
| 会社全体の診断・資本配分 | [capital-efficiency-analysis.md](references/capital-efficiency-analysis.md)：ROIC・ROA・ROE、デュポン分解と経年変化から課題へ。事業改善と分母圧縮、指標水準と変化要因を区別 |

重要なコメントは「数値根拠 → 背景 → 課題 → 改善案・条件 → 確認KPI」を揃え、会社の説明と分析者の推論を分ける。不足資料は判断保留と必要情報を示す。通常の分析で書籍原本を開かず、整理済みの判断基準・書籍参照ノートを使う。原本確認はスキル構築・改訂時だけとし、原本の有無を通常実行の条件にしない。

## 制作と検証

- **Excel：** [workbook.md](references/workbook.md)と利用可能なスプレッドシート作成スキルを使う。ライブ操作なら対応スキルを選び、特定の環境・ライブラリを固定しない。分析コメントシートに各社分析・比較・改善優先順位を保持する。
- **Wordを明示依頼された場合：** 文書作成スキルで同じ出力フォルダへ別ファイルを作る。結論、主要数値、5区分の分析・課題、各社セグメント表・解説、全体診断、比較、改善優先順位、出典・比較条件・制約を依頼範囲に応じて収録。Excelとの期間・単位・数値・結論の一致と、改ページ・表・文字の表示を確認する。
- **検証：** 原資料照合、独立計算、Excel数式の再計算、表示確認を分けて実施・記録する。実施できなかった確認を完了と報告しない。
- **報告：** 結論を先に、数値・比較から事業上の理由と課題を説明し、成果物・主要な発見・制約を伝える。株価評価・投資推奨は依頼範囲に限る。

## 分析完了後のHTML連携

直接依頼された分析の完了後は[html-handoff.md](references/html-handoff.md)に従い、引継ぎ情報を整えてHTML化を一度提案する。HTML不要の指定やHTMLスキルからのデータ準備呼出しでは提案しない。出力を選択済み・最初から依頼済みなら再確認せず作成・検証・引き渡しまで進める。

経営分析ダッシュボード（BS・PLボックス図入り）はfinancial-analysis-dashboardが担当する。Excel・本文・セグメント・全体診断の根拠と結論を保持し、HTML化を追加調査・期間拡張・株価更新の許可に広げない。

移植元と調整内容を確認する場合のみ[provenance.md](references/provenance.md)を読む。
