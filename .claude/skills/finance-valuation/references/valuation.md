# 企業価値評価

## 手法選択と前提

評価基準日、通貨、事業範囲、持分範囲、評価目的を固定する。金融機関は株主価値モデル（DDM、残余利益、P/BとROE等）を検討し、金融子会社を持つ複合企業はSOTPや非金融事業DCF＋金融事業価値を検討する。通常のUFCF/WACCを金融連結にそのまま使わない。

根拠のない「業種別標準倍率」「ERP5〜7%」「非上場割引15〜30%」を実在企業の既定値にしない。ユーザー指定・観測値・独自仮定を区別する。上場区分未確認を非上場とみなさない。明示的な試算で仮定を使う場合は入力欄にその性質と感度を示す。

## DCF

予測期間は事業の安定化までを考慮して設定。簡易試算で5年などを置くときは仮定とする。売上は可能なら数量×単価や事業別ドライバーから予測し、利益率、税金、D&A、設備投資、営業運転資本を連動させる。指定前提を無断で業界値に置き換えない。

```text
EBIT = EBITDA − D&A
NOPAT = EBIT − 営業利益に対応する現金税金
UFCF = NOPAT + D&A − Capex − Δ営業運転資本
Ke = Rf + βL × ERP + 根拠のある追加プレミアム
WACC = Ke × E/(D+E) + Kd × (1−税率) × D/(D+E)
βU = βL / [1+(1−税率)×D/E]
βL(target) = βU × [1+(1−税率)×目標D/E]
TV(g) = 正常化UFCF(N+1)/(WACC−g)
TV(exit) = 最終年の対応指標 × 出口倍率
EV = Σ[UFCF(t)/(1+WACC)^t] + TV/(1+WACC)^N
TV寄与率 = PV(TV)/EV
```

単純なEBIT×税率はモデル仮定であり、赤字時に自動的な還付を作らない。欠損金利用と税効果の実現性を扱う。営業運転資本から現金・有利子負債を除き、増加を正のΔとする。UFCFとCFO−CapexのCapexは支出額を正数で入力する。原CF表の負数から換算する場合は元符号を保持した別の入力行で正数化し、二重反転を防ぐ。

Rf・ERP・成長率・CFは通貨、名目/実質、評価時点を整合させる。WACCの資本比率は市場価値・目標構成を用い、過去の簿価比率を無説明で流用しない。ベータ調整式は負債ベータ等を省略した近似とし、適用条件を説明する。サイズ・国リスク等の二重加算を避ける。

WACCを直接指定されたらそれを入力とし、CAPMの部品を捏造しない。年度末/期中割引とstub期間を明示し、TVの割引時点もそろえる。gはWACC未満を必要条件とし、長期成長に必要な再投資を最終年のCFに反映する。安定状態で再投資率=g/ROICという整合確認も使える。最終年CF×(1+g)の簡便法ならその限界を記す。

TV比率が高いときは終価前提への依存を説明し、固定的な「適正比率」で合否を決めない。WACC×gまたはWACC×出口倍率の感度を示す。g≧WACCのセルは無効理由を表示する。

## EVから株主価値

```text
親会社株主価値 = 営業事業EV
                 + 余剰現金 + 別評価の非事業用資産
                 − 対応する有利子負債 − その他債務性項目
                 − EVに含まれる非支配持分価値
1株価値 = 親会社株主価値 / 対応する希薄化後株式数
```

営業に必要な現金まで余剰現金として加算しない。総現金を使う慣行を採る場合はその前提を示す。ネットデット方式でも別掲方式でも、現金・証券・年金不足・リース・非支配持分を二度調整しない。DCFに含まれない関連会社価値は必要に応じ別評価で加える。連結利益を用いていなければ非支配持分を自動控除しない。自己株式、潜在株式、オプション対価と希薄化の二重計上を確認する。

## コンプス・類似取引

企業の事業・地域・成長率・収益性・資本集約度を根拠に比較対象を選び、除外理由も残す。同一基準日の株価、発行株式数、ネットデット等の情報時点を記し、LTM/NTMや実績/予想、連結範囲を合わせる。

- EV/Revenue、EV/EBITDA、EV/EBITは事業価値の倍率。PER・PBRは株主価値の倍率であり、適用後にネットデットを再控除しない。
- 利益がゼロ以下の利益倍率はN/Mとし、統計から除く。外れ値は理由なく削除せず、対象数、中央値、四分位、採否根拠を示す。赤字だから売上倍率が適切とは限らない。
- 取引倍率では公表日/完了日、取得持分、支払対価と引受負債、アーンアウト、シナジー、指標期間を確認する。取引金額を根拠なくEVと呼ばない。
- 非流動性・支配権・少数持分の調整は評価対象と根拠に応じて採用する。支配権を含む買収倍率に追加の買収プレミアムを機械的に加えない。

比較可能なデータがなければ当該評価は未算定とする。複数手法のレンジを単純平均したり、重なりだけで正解と扱ったりしない。レンジの違いを説明し、目的に応じた重視理由を示す。フットボールチャートは必要な手法が複数あるときに使う。
