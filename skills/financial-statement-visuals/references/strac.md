# PL STRAC風ボックス図

## 目的と標準構成

売上高から費用・利益への分解を、階段状の箱で表す。標準の読み順は「売上高 → 売上原価／粗利益 → 販管費／営業利益 → 税引前利益 → 法人税等／連結全体の純利益」。経常利益が開示されている場合は営業利益と税引前利益の間に置く。同じ数値を隣の段で再掲する場合、それらを合算する図ではないと説明する。

- 左端に売上高の縦列、隣の上段に売上原価、下段に粗利益を置く。
- 粗利益の隣を販管費と営業利益に分解する。他の営業損益がある場合は独立項目で橋渡しする。
- 右側に営業外・特別損益等と税金をつなぐ。PLだけの依頼なら借入返済や設備投資まで追加しない。
- 複数社は同じ順序・色・指標定義で並べる。横幅は読み順のためのレイアウトで、金額を表さない。高さを金額に比例させ、面積比例とは説明しない。
- 「売上高を100とした構成比」と「同じ金額の高さ」を切り替えられるようにする。金額モードは全社・全段階の最大値を含む共通スケールを使い、配列先頭の企業の売上を固定上限にしない。

## データ契約

特定企業名・保存場所・年度・通貨・単位を固定しない。企業単位で以下を受け取る。

| 項目 | 必須性・扱い |
|---|---|
| 企業名、対象期間、連結／単体、会計基準、通貨、原数値単位 | 必須。期末日だけでなく対象期間を保持 |
| 項目ごとの出典URL、資料名、ページ、原表示名 | 必須。計算値は式と入力項目を保持 |
| 売上高、売上原価 | 原価型STRACの必須入力。欠ける場合は当該分解を未表示とし、ゼロや業界平均で補完しない |
| 粗利益、販管費、営業利益 | 開示値優先。粗利益は売上−原価として計算可能。販管費不明なら未開示扱いとし、差額を販管費と決めつけない |
| その他営業損益 | あれば保持。粗利益−販管費＝営業利益を全社に強制しない |
| 経常利益、営業外損益、特別損益、税引前利益 | 開示に応じて任意。経常と税前は別フィールド |
| 法人税等、連結全体の純利益、親会社帰属利益、非支配株主帰属利益 | 純利益まで描く場合に定義を確認。税前−税金の到達点は原則として連結全体の純利益 |
| 非継続事業損益等 | 税前利益が継続事業のみの場合などに追加。原表に沿った橋渡しにする |

未取得・非開示は `null` で保持し、実際のゼロと区別する。端数差は公表値を変更せず、原単位で残差を保存する。費用は原則として控除額を正値で保持し、利益／損益差額は符号付き。戻入・税効果による負の費用は符号を維持する。

## STRAC用語の境界

標準ラベルは「売上原価」「粗利益」「販管費」とする。公表PLに固定費／変動費の根拠ある分解がなければ、「変動費」「限界利益」「固定費」に名称を置き換えない。

完成HTMLに次の意味を明記する。

> 売上原価を用いたSTRAC風表示です。売上原価にも固定的な費用が、販管費にも変動的な費用が含まれます。粗利益は限界利益ではなく、この図だけで限界利益率・損益分岐点・労働分配率を算出するものではありません。

人件費や減価償却費の内訳を推定で分割しない。別注記の人件費等を使う際も、売上原価・販管費の対象範囲と一致するか確認し、二重計上を防ぐ。

## 例外処理

- **経常利益なし：** IFRS・米国基準などで未開示の場合、その段を省略し「営業利益 → 金融損益等 → 税引前利益」と原表に沿って表示する。差額しか確定できなければ「営業利益から税引前利益への調整（純額）」とし、内訳名を推測しない。
- **経常利益と税引前利益が異なる：** 特別損益などを別段に追加する。同じ箱やラベルで兼用しない。
- **負値：** 赤字、営業外損失、税金戻入等を絶対値の正の利益箱に変えない。負のSVG高さも禁止。ゼロ線付きの上下分岐図、または符号付きの増減ブリッジに該当段を切り替え、控除／増加の意味を示す。正値専用レイアウトに収まらない場合は明細表を併記した符号付きブリッジを代替とする。
- **売上ゼロ・負値：** 売上比は「算出不可」。構成比モードを無効化し、絶対金額の符号付き表示を使う。ゼロ除算を避ける。
- **その他項目・未確定残差：** 原表を調べてから橋渡しを作る。根拠不明の差額を「その他費用」に押し込まない。未解消なら未照合と表示し、該当段は確定図として出さない。
- **極小額・ゼロ：** 箱の高さを読みやすさのために水増ししない。引出し線や欄外ラベルを用い、ゼロは数値で表示する。
- **大幅な営業外利益等：** 税前利益が売上を超える場合も全段が収まるようにスケールと余白を自動調整する。

## HTMLと検証

- ネット接続不要の単一HTMLを基本とし、インラインSVG、凡例、読み方、比較条件、出典リンク、原単位の元データ表を含める。画像化だけで済ませない。
- 金額と売上比を併記する。比率は丸め前の原数値から計算し、表示の丸めで合計100にならない場合は注記する。
- 小画面では図を横スクロール可能にし、印刷では横幅を用紙内に収める。ボタンには状態表示とキーボードフォーカス、SVGには説明を付ける。
- 原表に応じて売上−原価＝粗利益、粗利益−販管費＋その他営業損益＝営業利益、営業利益＋営業外損益＝経常利益、経常利益＋特別損益＝税前利益、税前−税金＋非継続事業等＝連結純利益を照合する。適用されない式は省略し理由を残す。
- 許容差を一律1百万円にしない。原資料の表示単位・丸め方・集計項目数から判断し、各残差を原単位で列挙する。説明の付かない差はエラーとして扱う。
- 両表示モードで実行エラー・NaN・Infinity・負の寸法・領域外の箱を確認。正常な黒字例に加え、営業赤字、負の営業外損益、経常利益なし、税金戻入、売上ゼロ、極小利益、売上超過の税前利益を確認する。
- 実ブラウザでデスクトップ・小画面・両モード・印刷表示の文字重なりを確認する。ブラウザが利用不能なら数値・SVG配置・JS実行を代替検証し、目視未確認と報告する。アクセス制限を回避しない。

## 複数年度の場合

[multi-year-data.md](multi-year-data.md)の年度別データと[html-interaction.md](html-interaction.md)の共通操作を使用する。最新年度初期表示、年度切替、同一縮尺、年度別注記・出典を適用する。統合出力では図切替時に選択状態を保持し、過去年度も検証する。
