# HTML内の図切替と年度選択

## 共通の年度選択

- 初期表示は各社の最新表示対象通期。市場指標は独立した基準日の表示を保つ。年度選択で最新株価を過去年度の評価へ付け替えない。
- 3図は選んだ年度の図、元データ表、見出し、会計ラベル、単位、出典、注記を一緒に更新する。値のない年度は未取得と示し、隣の年度を代入しない。
- 経営分析ダッシュボードの年度切替は要約の対象年と対象期間表の強調列に反映する。推移・全明細表は対象期間の全年度分を維持する。市場欄は「株価基準日」を明示して独立表示する。
- 会社間で決算期が異なる場合、画面に各社の実際の対象期間・期末を表示する。暦年を無理に同一期へ変換しない。必要なら会社別に年度選択を置く。
- 単年データは不要な年度選択を出さない。1社はその会社の図を表示し、比較のための架空企業を追加しない。
- 金額モードは、同通貨・同単位にした全表示対象企業・全対象年度の値を含む共通スケールを既定にし、年度切替だけで高さの意味が変わらないようにする。構成比モードは各年の分母を明記する。極端値で読みにくい場合は年度内縮尺も選択可能にし、縮尺変更を表示する。

## 図の切替と単体動作

標準の財務図解は1HTML内でBox・サンキー・STRACを切り替える。単独図では図切替不要。明示された分割出力では各ファイルに担当図を収録し、希望時のみ図間のリンクを付ける。この図切替仕様は経営分析単独には適用しない。経営分析ダッシュボードに収録するBS・PLボックス図は図切替を持たず、ダッシュボードの年度選択に連動させ、金額／構成比の切替を付ける。年度と企業の選択を保持し、図固有の縮尺は明示する。2社同時表示に対応しない図では対象企業を選べるようにする。タブは選択状態、対応パネル、矢印キー・Home/Endとフォーカスを扱う。`?company=ID&period=FY2025#sankey`などで状態を復元でき、無効な値は通知して有効な初期値へ戻す。複数社別年度の場合は必要な選択をURLに含める。

経営分析との相互リンクは明示依頼時のみ。両HTMLが存在する場合に限り、outputsのファイル名で会社・年度を引き継ぐ。別々に実行した成果物の接続を必須にしない。

納品HTMLは同一dataset_idの必要データと全図の実装を内包し、そのファイルだけでネット不要で開ける。別HTMLのiframe srcやローカルJSON読込みに依存しない。JSON埋め込み時は `<` 等を安全にエスケープし、科目名・注記など外部テキストをHTMLとして実行しない。共通JSONのパスをfetchするだけの出力にしない。外部へのリンクは出典閲覧のために使う。

キーボード操作・フォーカス・選択状態を示し、図には説明と表を添える。小画面では表・図だけを横スクロールできるようにする。印刷ではそのHTMLに収録した全図を表示し、選択年度と基準日を残し、詳細表・分析本文・セグメント解説・課題がタブや折りたたみの非表示状態で消えないよう印刷時に展開する。
