# 経営分析ダッシュボードの構成

## 探索型の構成

構成指定がなければ探索型。冒頭でAIの結論や推奨順位を確定せず、読み手が数字から考える入口を作る。明示的に「結論先行」「意思決定支援型」を求められた場合は結論と優先課題を先に置ける。「経営会議向け」「幹部向け」は分析の深さを指定する語であり、それだけで結論先行へ切り替えない。

1. **問いを持つ。** 対象企業・期間・比較条件と、基本3問程度の中立的な問いを置く。標準の3問は、最後のまとめと対になる「この会社の強みは何か」「弱みと課題は何か」「今後、どちらの方向に進むべきか」。各問いの根拠の場所に、最後のまとめへのリンクを含め、冒頭で「答え合わせは最後のまとめにある」と案内する。問いの数・文言はデータと利用者の指定に合わせ、会社別の結論を疑問形にするだけの誘導質問にしない。
2. **数字を探索する。** 各問いを関連する図・数表・本文アンカーに結び、見る指標と比較操作を短く案内する。年度・企業・金額と比率など、実際にあるデータで比較できる操作を使う。既存の年度切替とアンカーでもよく、探索型のために新機能や入力フォームを追加する必要はない。単年に不要な年度切替や、未取得系列を作らない。
3. **解釈を検討する。** 図表の後に、確認できた事実、AIの解釈・仮説、別の説明が成り立つ条件、判断に必要な情報を示す。競合する仮説が根拠付きで考えられる場合は、どの資料・KPIで区別できるかを添える。明確な事実を曖昧にしたり、根拠のない対立仮説や同じ重みの両論を作ったりしない。
4. **人間が判断する。** 最後の「強み・弱み・課題・戦略の方向性」のまとめに、各社の「まだ分からないこと（断定できないこと）」の行と、両社に共通して残る問いを入れる。別に「分かったこと／断定できないこと／人間が判断すること」の欄は作らない（まとめと重複するため）。各社の優先課題・改善案は根拠と条件を持つ分析上の候補として残し、「何を優先するか」「何が分かれば判断を変えるか」を読み手に返す。人間の判断を単なるAI結論への賛否にしない。

探索型は分析を省くことではない。5区分の本文、セグメント数表・解説、全体診断、課題・提案・優先理由、出典は保持する。通常表示で「問い → 根拠 → 解釈」の順に読み進められるようにし、分析全体を折りたたみやクイズの回答後に隠さない。ただし、5区分の数表・2社比較表・本質的な課題・優先順位・まとめは通常表示とし、5区分の各社の長い本文、全体診断の「元分析の全体の結論」、詳細三表・市場指標・出典は、最初は折りたたんで表示する。目次や本文のリンクから飛んだときは自動で開き、年度を切り替えても開閉の状態を保つ。問いを末尾に付けただけの結論先行ページは探索型とは扱わない。閲覧だけで分析を理解できる構成にし、利用者の入力・提出・討議を無断で必須にしない。

例えば増収減益の会社では、「売上の増加は利益に結び付いたか」から売上・利益率の比較へ進み、確認済みの費用・事業構成を示す。その後に未確認の価格・数量・一時要因を分け、どの内訳が分かれば改善策の優先順位を変えるかを問う。会社を変えるときは名称だけでなく、この数値根拠と判断条件を作り直す。

## 入口の構成

経営陣・幹部社員が単体で財務状況と経営課題を理解できるHTML。[経営会議向け本文の要件](management-analysis.md)を必須とし、詳細三表・指標・セグメント表・分析本文・定義・出典を収録する。5期を標準とするが、指定期間・既存分析の期間を優先する。以下の推移表は対象期数に合わせ、2期を5期に拡張しない。

| 表示領域 | 必須内容 |
| --- | --- |
| 冒頭 | 探索の問い（基本3問程度）と関連図表への導線、用語の早見表（ROE・ROIC・NOPAT・FCF・EBITDA・DIO・CCC・手元資金・減損・のれん・WACC・PER/PBRなど、本文に出る略語の一行説明。最初は折りたたみ、指標の定義へリンク）、対象企業、表示通期、通貨・単位・連結範囲、入力資料の基準日、年度選択、依頼範囲内で生成済みの図へのリンク |
| 要約 | 最新年度の売上・営業利益率・ROE・自己資本比率・FCF等と、元分析で確認できる事実・制約。解釈と優先順位は根拠を見た後に示す。未入手値は理由を表示 |
| BS・PLボックス図 | 要約の次に置く。選択年度のBSとPLを各社並べ、全社・全年度の共通縮尺で描く。構成比の切替、元データ表（金額・構成比・出典）、「BSは期末残高・PLは年間合計、同額の重複表示は足さない」の注記。仕様は[boxes.md](../../financial-statement-visuals/references/boxes.md) |
| 対象期間の推移 | 売上・利益、利益率、資本構成、営業CF・FCFの必要なチャート。年度は古い順。単位が違う系列を同じ軸へ混ぜない |
| 詳細三表 | PL・BS・CFの全明細×対象年度。原科目、小計・階層、注記内訳、単位、欠損理由を保持。タブ・折りたたみ・横スクロールで読めるようにする |
| 経営指標 | 収益性・成長性・財務健全性・資金創出力の年度表。CAGRは期間・年数を併記。定義と入力値へたどれる |
| 市場指標 | 株価・時価総額・実績PER・PBR。市場基準日、EPS年度、BPS期末、株数時点、採用定義を表示 |
| 5区分の分析と課題 | PL・BS・CF・経営指標・セグメントそれぞれの結果・数値根拠・背景・経営への影響・課題。2社なら区分ごとの比較と会社別の課題 |
| セグメント表と解説 | 各社の対象期別売上・利益・利益率、定義・消去・調整、事業の役割・変化・資源配分の課題 |
| 本質的な課題と優先順位 | 先頭に本質的な課題（各社2〜3件。症状の数値→因果→根本原因、放置時の影響、確かめる情報・KPI、対応の方向）。続いて本質的な課題にひも付けた優先順位の候補、優先理由、対応条件・KPI。「分かったこと／断定できないこと／人間が判断すること」は最後のまとめに統合する |
| 強み・弱み・課題・戦略の方向性（まとめ） | 分析本文の最後（課題と判断の後、資料の前）。各社の強み・弱み・課題・今後の戦略の方向性を、2社なら並べて比較する。下記「強み・弱み・課題・戦略の方向性のまとめ」に従う |
| 出典・定義 | 元資料リンク・ページ、計算式、比較条件、分析上の仮定、欠損・未照合事項 |

BS・PLボックス図はダッシュボード内に収録し、別ファイルの図解へのリンクは付けない。別の入口HTMLは追加しない。既存分析コメントを引き継ぐときは根拠・仮説を区別し、極小自己資本による高ROEを無条件に好評価しない。

## 強み・弱み・課題・戦略の方向性のまとめ

分析本文の最後（「経営課題と人間の判断」の後、詳細三表・市場指標・出典などの資料の前）に置き、それまでの分析を読み手が一枚で振り返れるようにする。新しい分析を足す場所ではなく、前の区分で示した根拠をまとめ直す場所とする。

- **4つの欄**：各社について「強み」「弱み」「課題」「今後の戦略の方向性」を、それぞれ2〜3項目で示す。2社なら会社を列、4つの欄を行にした表で並べる。
- **強み・弱み**：財務数値と事業の事実から言えることに限る（例：高い自己資本比率、利益の大半を一つの事業に頼る構造）。各項目に根拠の数値・年度と、本文の該当箇所へのリンクを付ける。同じ事実が見方によって強みにも弱みにもなる場合は、両方に書いて関係を示す。
- **課題**：「経営課題と人間の判断」の本質的な課題と一致させる。別の言い方で新しい課題を増やさない。
- **今後の戦略の方向性**：各社2つ、課題への対応として性格の違う方向性を並べる（例：財務余力を厚く保ち本業に集中する／借入も使い成長投資・M&Aへ進む）。それぞれに狙い・選ぶ条件・副作用やリスク・確かめるKPIを添える。どちらが良いかの順位や推奨は付けず、「どちらを選ぶか、組み合わせるかは経営陣が決める」と明記する。
- **事実と仮説の区別**：開示から確かめた事実と、AIの解釈・仮説を表示で区別する。未開示・未入手で書けない欄は空欄にせず理由を示す。
- **期間**：まとめは固定期間（対象期間の総括と最新期）として期間を表示し、年度切替に連動させない。

## 各社・2社比較の分析コメント

- 各社について成長性・収益性・安全性・効率性／資本収益性・資金創出力／利益の質・資本配分を説明する。2社比較では「観点／A社／B社／差の背景・比較限界／各社の課題と改善方向」の表と改善優先順位を表示する。未入手・非該当領域には理由を付ける。
- 重要な論点は数値根拠、確認された背景／仮説、課題・問題点、改善案と実行条件・副作用、確認KPIを揃える。高ROEや自己資本比率だけで優劣を断定しない。
- `visuals-handoff.json` の `analysis_commentary_path`、Excelのコメント、既存レポートから本文・参照を取り込む。Wordは任意の既存入力であり、新規作成を前提にしない。`segment_data_path` または既存Excel等からセグメント数表と解説も取り込む。数値だけの旧データではfinance-valuationの `references/analysis-commentary.md` に整理済みの判断基準と書籍参照ノートが利用可能なら使い、既存データ内でコメントを補う。これらのスキル内資料がなければ上記構成を適用し、書籍への新しい帰属は行わない。書籍原本を読み直したり、その再提示を求めたりしない。原本を今回読まないことを「書籍未照合」等の制約に数えない。既存分析の再利用では、ユーザー指定のない追加の外部取得を行わない。externalモードでは[共通データ契約](../../financial-statement-visuals/references/multi-year-data.md)の入力条件に従う。
- 企業の出典と書籍の読み方の根拠を別に掲載。元分析の解釈とHTML化時に追加した解釈を区別する。本文は数値の出典・定義へ戻れるようにする。
- コメントには対象会社・年度または分析期間を表示する。年度ごとのコメントがある場合は選択に追随させる。5期総括や最新期のみのコメントは独立欄に対象期間を固定表示し、過去期のコメントに見せない。過去期の文がない場合は未作成と表示する。

## 検証

- 全年度の切替で要約・図・元表・注記・出典が一致するか。最新年度初期表示、最古年度、欠損年度、企業切替、金額／構成比、リンク往復を操作する。
- 全明細の行数・年度数を共通データと比較。売上・資産・純利益・CF等の共通項目、代表的なROE/FCF/CAGR/PER/PBRを元分析と照合する。
- 市場指標の値・日付が年度切替で誤変化しないか。最新値だけなら5期の市場推移チャートを作らない。
- 0とN/AとN/M、負値、単位、表示丸めを区別する。元の計算定義は変更しない。
- [定性分析の受入確認](management-analysis.md#受入確認)を実施し、元分析の重要論点・セグメント表・課題の収録漏れを確認する。
- 探索型では、各問いから根拠の図表へ到達でき、事実と仮説を区別し、最後に読み手が判断する論点が残るかを確認する。企業差し替えでも問いと指標・事業特性が対応していることを確かめる。
- 実ブラウザの表示確認と構造・数値検証を区別して報告する。

## 資本効率から会社全体を診断する

- 探索の問いと主要数値を見た後に、ROIC・ROA・ROEをつなぐ全体診断を表示。ROE＝純利益率×総資産回転率×財務レバレッジを視覚化し、3要素の対象期間表と、データがある比較期間の変化寄与を添える。単年で前年データがなければ変化寄与は算定不能と明記する。
- finance-valuationの確定データに全体診断があれば値・定義・税率仮定・平均残高・寄与計算法・コメントをそのまま継承。ない場合は同スキルのcapital-efficiency-analysis.mdに従い、提供済みデータの範囲で算出・検証する。書籍原本へ戻らない。
- 高自己資本によるROE水準への作用と、期間中のROE低下要因を区別。低レバレッジを自動的に問題とせず、利益率・回転率を併せて読む。数学的寄与と事業上の因果を分ける。
- ROICは会社公表値・独自値・参考値を区別し、税率、投下資本、余剰現金・金融資産・リース・のれん・減損の扱いを説明。参考値を事業ROICに見せず、資本コスト未算定なら価値創造の判定は保留とする。
- 診断を資産売却・株主還元・借入と買収・本業改善の選択肢へつなぎ、会社別の優先度、効果と条件、KPIを示す。利益一定の分母圧縮と継続的な稼ぐ力を区別し、大企業買収や還元拡大を固定の推奨にしない。
- 年度連動する数値と、固定期間の要因寄与・総括コメントを区別して表示。初心者向けには平易な問いから3要素と診断へ進み、ROIC定義・感応度・買収条件は展開欄に収める。
- 検証では3要素積・寄与合計・参考ROICの入力値と式を元分析へ照合。単位、ポイント、仮定表示、固定コメントの期間、印刷と小画面も確認する。
