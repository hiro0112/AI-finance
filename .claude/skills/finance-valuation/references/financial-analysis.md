# 財務分析と比較可能性

## 観測値を固定する

「2026年3月期」とFY2025のような会社固有表記を実際の期末日に対応させる。実績・会社予想・市場予想を分け、未公表期を実績扱いしない。決算期変更、短期決算、LTM、通貨換算、継続事業・非継続事業、連結範囲変更を記録する。3期のCAGRの指数は1/2であり1/3ではない。

決算短信の主要値は有報で照合し、説明資料で事業要因を補足する。取得不能な資料はその旨を残す。PDFの図やスキャン表は目視し、符号、桁、注記を確認する。複数資料が一致しなければ丸め差か改訂差かを調べる。

## 指標の定義

依頼・業種に応じて必要な指標だけを選び、分母と期間を明示する。

| 指標 | 計算と注意 |
|---|---|
| 売上成長率 | 当期/前期−1。基準がゼロ・負なら機械的な成長率を避け差額を示す |
| 営業・純利益率 | 対応する利益/売上。純利益は親会社帰属か連結合計かを明示 |
| ROE | 親会社帰属利益/期首期末平均の親会社持分。3期分には4期末分の持分が必要。分母が負・極小なら解釈不能を明示 |
| ROA | 採用利益/平均総資産。利益の定義を固定 |
| ROIC | 調整NOPAT/平均投下資本。営業資産・負債からの定義と税前提を明示し、金融事業に機械適用しない |
| 自己資本比率 | 親会社持分/総資産。非支配持分を含む総資本比率と区別 |
| EBITDA | EBIT＋対応するD&A。会社調整EBITDAとは調整表でつなぐ |
| ネットデット/EBITDA | 負債・現金・リースの範囲を合わせる。EBITDAがゼロ以下ならN/M |
| CF | CFO、投資CF、財務CF、現金増減を表示。為替・連結範囲差も照合 |
| FCF | CFO＋投資CF、CFO−Capex、UFCFは別物。式と投資有価証券等の影響を明示 |
| 効率性・運転資本 | 総資産回転率、DSO・DIO・DPO・CCCを標準確認。[定義・欠損・近似と資金繰りの判断](working-capital-analysis.md)を適用。CCC＝DSO＋DIO−DPO。DPOは対応仕入高を優先し、売上原価代用は近似 |

欠損値をゼロに置き換えない。N/A（未入手・非該当）とN/M（計算できても意味が乏しい）に理由を添える。会社公表ROE等と独自計算が違えば両者を区別する。

## 基準・事業の差

- IFRS、日本基準、US GAAPの営業利益・経常利益・税引前利益は名称だけで対応させない。R&D資産化、のれん償却、減損、リース、金融損益の表示差を確認する。数量的調整ができない差は注記し、調整済みと呼ばない。
- 製造＋販売金融では、金融債権・調達負債が連結のレバレッジやCFを大きく動かす。開示があれば非金融事業と金融事業を分ける。セグメント消去前後、その他事業の含有、会社のネットキャッシュ定義を確認する。
- 持分法会社を比例連結した参考値、卸売/小売台数、ブランドや地域範囲の差を混在させない。合算・単価計算には範囲の一致が必要。
- 一時利益・減損・再編費用は報告値に残し、正常化する場合だけ根拠付き調整表を追加する。「一時的」と会社が述べていても再発性を検討する。

結論は規模、稼ぐ力、財務余力、投資と株主還元、将来の制約に分けて考える。強み・弱みには比較根拠を示し、課題には今後見る指標を添える。期間が異なる経営施策と業績を因果関係として断定しない。
